# My Portfolio 

A website with my projects presentations, testimonials and about me info. All the projects are described and illustrated, the technical stacks and delivery dates are available. My contact info is also presented.

## 🌐 Link

[oleksii-pavlov.netlify.app](https://oleksii-pavlov.netlify.app)

- **TypeScript**

## ✨ Quick Start

```bash
npm install
npm run dev
```
